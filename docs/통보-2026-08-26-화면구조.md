### 특히 봐 주면 좋겠는 것 4개

**① 경험치 팝업 자리가 하루에 세 번 바뀌었고 셋 다 실측이 이유다.**

```
① 오른쪽 열 카드      나타나는 순간 아래 카드 네 장이 밀렸다 — 실측 153px
                     방금 누른 먹이기 버튼이 손가락 아래에서 움직인다
② 화면 상단 중앙      밀림 0px. 그런데 방 밖이라 시선이 위로 튀었다가 돌아온다
③ 방 중앙 상단(지금)  씨앗이 오르는 곳도, 눈이 가 있는 곳도 펫이다
```

`position: absolute` + `pointer-events: none`이라 **떠 있는 2.6초 동안에도 아래를 누를 수 있다**(오른쪽 위 진화 버튼 포함). 여닫기를 키프레임 하나(2.6s)로 처리해서 `PetView`의 unmount 타이머와 값이 한 곳이다.

> **`prefers-reduced-motion`에서 `animation: none`을 쓰면 팝업이 안 사라진다** — 시작 상태(`opacity 0`)로 남아 보이지 않게 된다. 페이드만 남긴 별 키프레임으로 갈아탔다. 비슷한 연출을 추가할 때 같은 함정이 있다.

**② 1단계 외출이 "숨김"이었던 것은 규칙 두 개가 겹친 사고였다.** 8/26에 넣은 "IDLE + 친밀도 부족이면 카드를 접는다"에 1단계가 함께 걸렸다 — 알 단계에서는 친밀도가 0이기 때문이다. 결과가 *외출이라는 기능의 존재를 알 단계 내내 모르는 것*이었다.

두 규칙의 성질이 다르다. 친밀도 부족은 접어도 된다(모이면 저절로 나타나 그게 알림이 된다). 1단계는 안 된다(알 → 아기가 레벨 4칸이다).

`disabled`를 **쓰지 않았다.** 눌러야 이유가 나오는 버튼이라 클릭 이벤트가 와야 한다. `cursor`도 `pointer`다.

**③ 잠금 문구가 상수 하나로 모였다.** `lib/outing.ts`에 같은 문장이 두 번 하드코딩돼 있던 것을 `lib/pet.ts`의 `OUTING_LOCK_MESSAGE`로 합쳤다. 레벨을 `EVOLUTION_LEVEL.STAGE2`에서 만들므로 그 값이 바뀌면 문장이 따라간다.

**단계 이름(`아기`)이 두 곳에 있다** — `PetView`의 `STAGE_NAME[1]`과 이 상수다. `STAGE_NAME`은 화면 전용 배열이라 lib에서 참조하면 lib가 컴포넌트를 의존한다. 어긋나는 것은 `check:pet`이 막는다(단정 6건 추가).

**④ 여행일기 2단에서 1단 44rem을 고르지 않은 이유는 세로다.** 폭만 보면 1단이 이야기에 672px을 준다(2단은 416px). 그런데 1단은 펫 그림 + 제목이 200px을 세로로 먹고 이야기를 아래로 민다. 2단은 그 200px을 옆으로 치워 **펫 얼굴을 보면서 이야기를 읽게** 된다.

### 로컬 환경에서 확인한 것 2건 — **둘 다 코드 문제가 아니다**

**① 커뮤니티 사진 업로드가 로컬에서 IAM에 막힌다.**

```
POST /api/upload/community/presign   200  { uploadUrl, s3Key, expiresIn }
PUT  <uploadUrl>                     403  AccessDenied
     user/welli-diagnose is not authorized to perform: s3:PutObject
     on resource: arn:aws:s3:::welli-uploads-185236887369/...
```

presign이 정상 서명을 내주므로 `lib/uploads.ts`는 맞게 동작한다. **배포본은 Amplify 역할을 쓰므로 이 제약과 무관하다.** 로컬에서 사진 첨부를 시험해야 하는 사람에게 권한이 필요하다. 403이라 객체는 생성되지 않았다.

**② `~/.aws/credentials`에 `[default]`가 없으면 500이다.** 이름 있는 프로필만 있으면 SDK가 자격증명을 못 찾는다(`CredentialsProviderError`). `.env`에 `AWS_PROFILE=<이름>`을 적으면 해결된다 — `.env.example`은 공유 파일이라 손대지 않았다. **여기에 키를 추가할지는 E 판단이다.**

### 넘기는 것 — `check:uploads`가 `develop`에서 깨져 있다 (미수정)

`8a4316b`가 `lib/uploads.ts`에서 webp를 지웠는데(Guardrails가 PNG·JPEG만 받아서) `scripts/check-uploads.ts:57`의 단정이 안 따라갔다.

```
uploads.ts:115       "JPG·PNG 이미지만 올릴 수 있습니다"
check-uploads.ts:57  /JPG·PNG·WEBP/.test(err.message)   ← 여기서 실패한다
```

**기능은 정상이다** — gif·webp가 실제로 막힌다. 정규식에서 `·WEBP`를 지우면 끝이다. E·D 소유라 고치지 않았다.
