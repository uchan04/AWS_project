## 3. 명세와 구현이 갈린 항목 (발표 전 정리 필요)

1. **진단 문항 6개 → 13개 + 조기 종료.** 의도적 결정(결정 변경 3번)인데 `SPEC.md` 3절이 6개로 남아 있다. 심사에서 문서와 화면이 어긋난다
2. **진단 LLM 2종 컷.** 지금 진단의 LLM은 결과 근거 3줄 하나뿐이다. "LLM은 문장 생성과 enum 변환만" 이라는 13절 답변을 근거 3줄 기준으로 고쳐야 한다
3. **커뮤니티 주제 추천이 LLM이 아니다.** 정적 상수다
4. **희망 문구 배너 미구현.** 상수 3~5개 + 배너 한 장이라 30분 작업
5. **7일 streak 별조각 보너스 미구현.** 수급표(63.6/일)는 이걸 안 넣어도 성립한다(별조각 60 완주 보너스가 대부분) — 넣지 않고 명세를 고치는 쪽이 싸다
