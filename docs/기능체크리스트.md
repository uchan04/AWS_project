#### API

| 기능 | 상태 | 파일 |
|---|---|---|
| `POST /api/auth/signup` — 이메일 정규식 + 8자 검증 | ✅ | `app/api/auth/signup/route.ts` |
| 중복 이메일 사전 조회 → `EMAIL_TAKEN` 400 | ✅ | 유니크 제약 위반을 500으로 흘리지 않는다 |
| scrypt 해시 저장, `cognitoSub = local:<uuid>` | ✅ | 평문·복호화 가능 형태 저장 0건 |

| Cognito 경로 (`USER_PASSWORD_AUTH`) 폴백 | ✅ | Google 계정은 `passwordHash`가 `null`이라 이쪽으로 내려간다 |
| 실패 문구를 하나로 통일 (계정 존재 여부 비노출) | ✅ | `NotAuthorized`·`UserNotFound` 둘 다 같은 401 문구 |

| `GET /api/auth/google` — Hosted UI 리다이렉트 | 🔧 | 도메인 스킴 정규화 + `redirect_uri`를 `APP_ORIGIN`에서 만든다. `state`를 만들어 `oauth_state` 쿠키에 심는다. **콘솔 IdP 연결 미완** |
| `GET /api/auth/callback` — code → 토큰 교환 | 🔧 | `state` 대조 후 쿠키 삭제(CSRF). 실패 사유를 CloudWatch에 남기되 `code`는 안 남긴다 |
| **모든 로그인 경로가 자체 세션 쿠키(7일)** | ✅ | Cognito 액세스 토큰(1시간, refresh 없음)을 쿠키에 담지 않는다. `signInWithCognitoToken()` 경유(2026-08-22) |
| 미설정 시 503 + "이메일로 로그인해 주세요" 안내 | ✅ | `COGNITO_DOMAIN`이 비어 있어도 500이 아니다 |
