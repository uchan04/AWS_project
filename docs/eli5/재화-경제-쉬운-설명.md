# 재화 경제 — 쉬운 설명

대상: A~E 전원. 특히 "미션 보상 좀 올려도 되나요"를 묻고 싶은 사람.
읽는 시간: 8분. 값은 전부 코드에서 확인한 실제 값이다(2026-08-25 기준).

---

## 0. 30초 요약

재화가 3종이고, **각각 하는 일이 다르다.**

```
씨앗  🌱  ──►  펫을 먹인다  ──►  레벨·진화
별조각 ✦  ──►  변형 스킨을 산다 (2,500)
친밀도 ♥  ──►  배경·치장을 산다 (600~2,800)
```

**규칙 하나만 기억하면 된다.**

```ts
user.seeds += 10                                         // 금지
calculateReward(user.activePetSkin, { seeds: 10 })       // 필수
```

캐릭터 고유 효과(씨앗 +15% 등)가 저 함수 안에만 있다. 직접 더하면 배율이 빠진다.

## 1. 수도꼭지와 배수구 비유

재화 경제는 **욕조**다. 수도꼭지(수급)로 물이 들어오고 배수구(소모)로 빠진다.

```
   수급 (수도꼭지)                        소모 (배수구)
  ┌──────────────┐                      ┌──────────────┐
  │ 일일 미션     │                      │ 펫 먹이기     │
  │ 출석          │  ──►  🌱 씨앗  ──►   │ (경험치)      │
  │ 방치형        │                      └──────────────┘
  │ 단계 미션     │
  └──────────────┘

  ┌──────────────┐                      ┌──────────────┐
  │ 일일 전체완료 │                      │ 변형 스킨     │
  │ 출석 4·7일차  │  ──►  ✦ 별조각 ──►  │ 2,500        │
  │ 단계 미션(3구간+)│                   └──────────────┘
  └──────────────┘

  ┌──────────────┐                      ┌──────────────┐
  │ 글 · 댓글     │                      │ 배경 · 치장   │
  │ 챗봇 · 모임   │  ──►  ♥ 친밀도 ──►  │ 600~2,800    │
  └──────────────┘                      └──────────────┘
     하루 상한 100
```

**세 욕조가 서로 안 통한다.** 이게 지금 구조의 특징이고, 바꾸려는 지점이다(6절).

## 2. 수도꼭지 — 정확한 값

### 🌱 씨앗

| 어디서 | 얼마 | 조건 |
|---|---|---|
| 일일 미션 5개 | 10+10+10+15+15 = **60** | 매일 초기화 |
| 출석 | 1~7일차 10·15·20·25·30·35·40 = 주 **175** (하루 25) | 7일 주기로 반복 |
| 방치형 | 시간당 **2** = 하루 48 | 상한 50시간(100개). 넘으면 안 쌓인다 |
| 단계 미션 | 미션당 **18 + 구간×4**, 한 단계 3개 | 1구간 66 / 10구간 174 |

**하루에 다 하면 약 133 + 단계 보상.**

### ✦ 별조각

| 어디서 | 얼마 | 조건 |
|---|---|---|
| 일일 미션 **전부** 완료 | **60** | 5개 중 하나라도 빠지면 0 |
| 출석 4일차 | 5 | |
| 출석 7일차 | 20 | 주 25 = 하루 약 3.6 |
| 단계 미션 | 미션당 **구간 − 2** (3구간부터), 한 단계 3개 | 1·2구간은 0 / 10구간 24 |

**1·2구간에 별조각이 없는 것은 의도다.** 방 안 미션에 별조각을 주면 **나가지 않는 쪽이 이득**이 된다.

### ♥ 친밀도

| 어디서 | 얼마 |
|---|---|
| 글 쓰기 | **20** |
| 댓글 | **5** |
| 챗봇 1턴 | **5** |
| 오프라인 모임 신규 신청 | **10** |

**하루 상한 100** (`AFFINITY_DAILY_CAP`). 글 5개면 채워진다.

> 눈여겨볼 것: **친밀도 수급처가 전부 "사람과 닿는 행동"이다.** 혼자 하는 미션으로는 1도 안 나온다.
> 이건 우연이 아니라 설계다.

## 3. 배수구 — 무엇을 사나

| 사는 것 | 화폐 | 가격 | 다 모으는 데 |
|---|---|---|---|
| 변형 스킨 | ✦ 별조각 | **2,500** | 약 39일 |
| 배경 6종 | ♥ 친밀도 | 600 (COMMON) | 6종 3,600 = 약 36일 |
| 치장(모자·목도리) | ♥ 친밀도 | RARE 1,000 / EPIC 1,800 / LEGENDARY 2,800 | |
| 펫 먹이기 | 🌱 씨앗 | 자유 | 아래 |

**39일과 36일이 우연히 비슷한 게 아니다.** 두 가격을 서로 맞춰서 정한 값이다.

### 씨앗 → 레벨 환율

```
씨앗 1개  =  경험치 10
Lv N 까지 누적 경험치  =  50 × N × (N−1)
```

진화는 3번 일어난다.

```
Lv 1 ─────► Lv 5 ─────► Lv 15 ─────► Lv 25
   1단        2단          3단          4단(최종)
             1,000경험치   10,500       30,000
             씨앗 100      씨앗 1,050   씨앗 3,000
```

## 4. 여기서 나온 문제 — 펫이 너무 빨리 다 자란다

계산해 보면 이렇다.

| 씨앗을 어디서 세나 | 최종 진화(씨앗 3,000)에 닿는 시점 |
|---|---|
| **단계 미션만** | **37단계** — 100단계 중 37 |
| 일일 + 출석 + 방치형 + 단계 (매일 다 하면) | **약 15일** |

```
1단  2단        3단        4단(최종)
├───┼──────────┼──────────┼──────────────────────────────────────────┤
1                                    37                            100단계
                                     ↑
                        여기서 펫은 더 이상 자라지 않는다
                        남은 63단계 동안 시각적 변화가 없다
```

**"동네 한 바퀴"(4구간)에서 펫이 다 자라고, "사회로 한 걸음"까지 63단계가 남는다.**

씨앗은 계속 들어오는데 쓸 곳이 먹이뿐이고, 먹여도 아무 일이 안 일어난다. **가장 어려운 미션을 하는 구간에서 보상 체감이 가장 낮다.**

이게 지금 기획 변경의 배경이다.

## 5. 지금 구조의 다른 문제 — 두 재화가 싸운다

```
      상점
       │
   ┌───┴───┐
   ✦        ♥
별조각    친밀도
(스킨)    (배경)
```

**같은 일(상점)을 두 재화가 나눠 한다.** 그래서 이런 일이 생긴다.

- 사용자는 "왜 배경은 친밀도로 사고 스킨은 별조각으로 사나"를 이해할 근거가 없다
- 친밀도를 열심히 벌어도 스킨에는 1도 못 쓴다 — **사람과 닿는 행동의 보상이 특정 물건에 갇힌다**
- `EffectType.AFFINITY` 스킨(친밀도 +%)이 사실상 "배경 할인 쿠폰"이 된다

## 6. 바꾸려는 것 — 펫 외출 (계획, 미구현)

```
     현재                          변경 후
                                                   ┌──► 🌱 씨앗 30~50
♥ 친밀도 ──► 배경            ♥ 친밀도 200 ──► 외출 ─┤
                                    4시간          └──► ✦ 별조각 30~50
✦ 별조각 ──► 스킨                                          │
                              ✦ 별조각 ──► 배경 + 스킨 ◄───┘
```

바뀌는 것 셋.

1. **친밀도는 상점을 떠나고 "외출 티켓"이 된다.** 사람과 닿아서 번 것으로 펫을 밖에 내보낸다 — 은유가 맞는다
2. **상점 화폐는 별조각으로 통일된다.** 배경 가격 600 친밀도 → **500 별조각**
3. **두 재화가 연결된다.** 외출 복귀에 별조각이 나오므로 `친밀도 200 = 외출 1회 = 별조각 30~50`이 **환율**이 된다

값의 근거는 이렇다.

| 값 | 왜 |
|---|---|
| 친밀도 **200** | 하루 상한이 100이라 **최소 2일에 1회**. 매일이면 사건이 아니라 일과가 된다 |
| 씨앗·별조각 **둘 다** 지급 | 「하나만」이면 절반의 외출에서 별조각이 안 나온다. 2일에 한 번인 이벤트에서 실망 확률 50%는 너무 높다 |
| 배경 **500** 별조각 | 6종 3,000 = **36일**. 지금 친밀도 3,600(36일)과 **정확히 같다** — 체감을 안 바꾸고 재화만 통일한다 |
| 외출 **4시간** | 방치형이 30분에 씨앗 1개라 그보다 확실히 길어야 구분된다. 오전에 보내면 오후에 온다 |

세부 계획(스키마·API·화면·검증)은 `docs/dev/pet.md`에 있다. **아직 코드도 스키마도 안 건드렸다.**

## 7. 보상값을 바꾸고 싶을 때 — 손대기 전에 볼 표

| 무엇 | 어느 파일 | 부작용 |
|---|---|---|
| 일일 미션 보상 | `prisma/seed/missions.ts` | **`db:seed`를 돌려야 반영된다.** 코드만 고치면 안 바뀐다 |
| 단계 미션 보상 | `lib/missions/bands.ts` `rewardForStage()` | 300슬롯 × 3종족이 전부 따라온다. **`db:seed` 필요** |
| 출석 보상 | `lib/missions/attendance.ts` | 코드 값이라 즉시 반영 |
| 방치형 시간당 | `lib/pet.ts` `IDLE_SEEDS_PER_HOUR` | 즉시 반영 |
| 친밀도 지급량 | `app/community/_lib/affinity.ts` | 즉시 반영. **하루 상한 100에 걸리는지 확인** |
| 스킨 가격 | `prisma/seed/items.ts` `VARIANT_PRICE_SHARDS` | **`db:seed` 필요** |
| 치장 가격 | `prisma/seed/items.ts` `PRICE_BY_RARITY` | **`db:seed` 필요.** 등급별로 6종이 한 번에 따라온다 |
| 레벨 곡선·진화 시점 | `lib/types.ts` `SEED_TO_EXP` `EVOLUTION_LEVEL` | **전원 합의.** 공유 파일이다 |

세 가지를 조심한다.

1. **`prisma/seed/` 값은 `db:seed`를 돌려야 반영된다.** 코드를 고치고 "왜 안 바뀌지"를 겪는 지점이 여기다. 그리고 `db:seed`는 공유 DB 쓰기라 **승인이 필요하다**
2. **한 재화만 보고 올리지 않는다.** 씨앗을 올리면 진화가 더 빨라지고(4절 문제가 심해진다), 별조각을 올리면 39일 기준선이 무너진다
3. **친밀도는 하루 상한 100에 부딪힌다.** 지급량을 올려도 하루 총량은 안 늘어난다 — 상한을 같이 올리지 않으면 아무 효과가 없다

## 8. 왜 이 함수 하나만 쓰라고 하나

```ts
calculateReward(skin, { seeds: 10 })
```

캐릭터마다 고유 효과가 있다 — 씨앗 +15%, 별조각 +10%, 친밀도 +20% 같은 것.

**그 배율이 이 함수 안에만 있다.** 그래서 두 가지가 보장된다.

```
직접 더하면  →  user.seeds += 10        →  배율이 빠진다 (효과가 없는 캐릭터가 된다)
두 번 통과   →  reward(reward(...))     →  배율이 두 번 곱해진다 (1.15 × 1.15)
```

**"획득"만 통과한다.** 구매·차감은 통과하지 않는다 — 배율을 얹으면 **싸게 사는 게 되기 때문**이다. 그래서 구매 코드는 이렇게 생겼다.

```ts
// 잔액이 충분할 때만 깎는다. 두 번 빨리 누르면 두 번째는 0건이 된다
updateMany({ where: { id, starShards: { gte: price } },
             data: { starShards: { decrement: price } } })
```

친밀도는 하나 더 있다 — `capAffinity()`. 글·댓글·챗봇·모임이 **하루 상한 100을 공유**하므로 각자 계산하면 상한이 4배가 된다.
