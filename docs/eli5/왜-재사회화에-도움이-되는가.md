# 왜 재사회화에 도움이 되는가 — 쉬운 설명

대상: 발표하는 사람, 심사 질문을 받는 사람, 그리고 "이거 그냥 체크리스트 앱 아닌가"를 스스로 의심해 본 사람.
읽는 시간: 10분. **숫자는 전부 실측이다** — 어디서 쟀는지 함께 적었다.

---

## 0. 30초 요약

한 문장으로 답해야 하면 이것이다.

> **"나가는 것"을 100개로 쪼갰다.**
> 그래서 오늘 할 수 있는 크기의 한 칸이 항상 있다.

```
방 안에서 → 집 안 생활 → 문 앞까지 → 동네 한 바퀴 → 가게와 시설
   → 조금 더 멀리 → 한마디 건네기 → 대화와 모임 → 관계 이어가기 → 사회로 한 걸음
```

`현관문 열어두기`(21단계)와 `상담이나 면접 다녀오기`(94단계)가 **같은 사다리 위에** 있다. 그 사이가 73칸이다.

---

## 1. 사다리 비유 — 왜 100개인가

고립·은둔에서 벗어나라는 조언은 보통 이렇게 생겼다.

```
      🏠 ───────────────────────────────────► 💼
     방 안                                   취업
       └─────────── 이 사이가 비어 있다 ──────┘
```

**칸이 없으니 오를 수 없다.** "나가 보세요"는 사다리가 아니라 절벽이다.

우리가 한 것은 절벽에 칸을 새기는 것이다.

```
🏠 ┬ 방 안에서        1~10   이불 정리 · 커튼 열기 · 물 한 컵
   ├ 집 안 생활      11~20   환기 · 그릇 하나 · 옷 갈아입기
   ├ 문 앞까지       21~30   현관문 열어두기 · 문 앞에 1분 서 있기
   ├ 동네 한 바퀴    31~40   20분 걷기 · 좋아하는 것 하나 찍기
   ├ 가게와 시설     41~50   밖에서 한 끼 · 상담 창구 알아보기
   ├ 조금 더 멀리    51~60   처음 가는 길 · 1시간 밖에 있기
   ├ 한마디 건네기   61~70   '이거 주세요' · 짧게 인사만
   ├ 대화와 모임     71~80   같이 밥 먹기 · 모임에 두 번째로 가기
   ├ 관계 이어가기   81~90   약속 지키기 · 먼저 연락하기
💼 ┴ 사회로 한 걸음  91~100  상담이나 면접 · 회복 계획 세우기
```

**한 칸의 높이가 "오늘 할 수 있는 정도"다.** `현관 밖에 1분 서 있기`는 "나가기"가 아니다. **문을 여는 것**이다.

`lib/missions/bands.ts`의 주석에 종착점이 적혀 있다.

> 100단계를 끝내면 "정기적으로 나가고, 사람과 약속을 잡고, 배우거나 일을 알아보는" 상태가 된다.

---

## 2. 사다리에 축이 두 개다

거리만 늘어나는 게 아니다. **사람과의 거리**가 따로 올라간다.

```
        거리 →
        방   집   문앞  동네  시설  멀리
사람 ↑                                   ┐
혼자    ●    ●    ●    ●    ●    ●      │ 1~6구간: 사람이 없다
한마디                              ●    │ 7구간
대화                                  ●  │ 8구간
관계                                    ● │ 9~10구간
                                         ┘
```

**1~6구간에 사람이 거의 없는 것이 의도다.** 공간을 넘는 것과 사람을 만나는 것은 다른 난이도다. 둘을 같이 올리면 둘 다 못 한다.

그리고 재화가 이 축을 따라간다.

| | 1·2구간 | 3구간부터 | 7구간부터 |
|---|---|---|---|
| 🌱 씨앗 | 있다 | 있다 | 있다 |
| ✦ 별조각 | **0** | 있다 | 있다 |
| ♥ 친밀도 | 미션에선 0 — **사람과 닿는 행동에서만** 나온다 | | |

**1·2구간에 별조각을 0으로 둔 이유가 명시적이다** (`bands.ts:64`):

> 방 안 미션에 별조각을 주면 **나가지 않는 쪽이 이득**이 된다.

보상 설계가 방향을 가리켜야 한다. 방 안에 머무는 것이 최적 전략이면 사다리가 아니다.

## 3. 무엇을 근거로 이 순서인가

우리는 임상 시험을 하지 않았다. **하지만 순서를 임의로 정하지도 않았다.**

두 가지 알려진 접근의 형태를 따랐다.

| 접근 | 한 줄 | 우리 구조의 어디에 |
|---|---|---|
| **행동활성화** | 기분이 나아지길 기다리지 않고, **먼저 작게 움직인다.** 움직임이 기분을 끌어올린다 | 1·2구간이 전부 "1분·한 컵·한 곳" 크기다. 의욕을 요구하지 않는다 |
| **단계적 노출** | 불안한 상황을 **작은 것부터 순서대로** 겪는다. 건너뛰지 않는다 | 문 앞 → 동네 → 가게 → 한마디. 한 칸이 앞 칸의 조금 더 먼 버전이다 |

문구도 그 원칙을 따른다.

```
"현관문 열어두기 — 1분만 열어둬요. 나가지 않아도 괜찮아요."
"신발 신고 5분 있기 — 나가지 않아도 좋아요. 신어보기만 해요."
"쓰레기 한 봉지 묶기 — 버리지 않아도 돼요. 묶어두기만 해도 충분해요."
```

**전부 "안 해도 된다"를 명시한다.** 미션이 요구가 되면 실패가 되고, 실패는 은둔을 강화한다.

## 4. 일부러 넣지 않은 것 — 이게 설계의 절반이다

심사에서 "왜 랭킹이 없나요"를 받으면 이렇게 답한다.

| 안 넣은 것 | 왜 |
|---|---|
| **랭킹·경쟁 지표** | 비교는 고립을 강화한다. 남보다 뒤처졌다는 신호가 앱을 끊는 이유가 된다 (`SPEC.md` 5절 의도적 배제) |
| **연속 달성 끊김 처벌** | "37일 연속이 끊겼습니다"는 복귀를 막는다. 하루 못 한 사람이 다시 안 온다 |
| **유형 이름 노출** | 진단 결과의 내부 유형명(8종)을 **화면과 API에 절대 넣지 않는다.** 낙인이 된다 (`bands.ts:33` 주석) |
| **사진 내용 판정** | "이 사진이 정말 산책인가"를 판정하지 않는다. 감시가 되면 안 한다 (`CLAUDE.md` 8절) |

그리고 **잠금 조건이 3개 중 2개다** (`REQUIRED_PER_STAGE = 2`). 주석이 이유를 적고 있다.

> 오늘 도저히 못 하는 미션 하나가 100단계 전체를 막으면 안 된다.

```
[85단계]  정기 활동 한 번 나가기 · 약속 지키기📷 · 정류장까지 가보기
          └──────── 이 중 2개면 86단계가 열린다 ────────┘
```

사진 미션인데 나갈 수 없는 날이 있다. 그날 사다리가 멈추면 안 된다.

## 5. 실제로 틀려 있었고, 고쳤다 — 이 트레이드오프가 핵심이다

여기가 이 문서에서 가장 중요한 절이다. **사다리를 만들었다고 사다리가 되는 게 아니었다.**

### 무엇이 틀려 있었나

100단계 × 3미션 = 300슬롯을 다 새로 쓰지 않았다. **미션 123개를 반복 배치**했다 — 한 번 하고 끝나면 습관이 안 되기 때문이다.

문제는 **무엇을 반복할지 고르는 규칙**이었다. "가장 오래 안 나온 것"을 골랐다.

```
가장 오래 안 나온 것  =  가장 먼저 도입된 것  =  1구간 미션
```

결과가 이렇게 나왔다.

```
94단계  상담이나 면접 다녀오기(새) · 배우고 싶은 것 찾아보기(10구간) · 기지개 한 번(1구간)
98단계  한 달 계획 세우기(새)      · 할 수 있는 일 알아보기(10구간) · 양치하기(1구간)
```

**면접을 다녀오는 단계에서 슬롯의 33%가 `양치하기`다.**

실측 세 가지:

| 쟀더니 | 값 |
|---|---|
| 복습 슬롯 중 1구간 출신 | **31%** |
| 최상단 10구간의 복습 중 7~9구간(사람 관련) 출신 | **0개** |
| 딱 한 번만 나온 미션 | `'이거 주세요' 말해보기` · `엘리베이터에서 인사` · `같이 밥 먹기` · `고맙다고 말하기` … **13개** |

`커튼 열기` 7회 대 `카페에서 주문하기` 2회.

**거꾸로였다.** 커튼 열기는 한 번 하면 이어지는 일이고, **사람에게 먼저 말을 거는 것이 반복이 필요한 일**이다.

### 트레이드오프 — 무엇을 포기했나

고치려면 하나를 버려야 했다.

```
      ① 확장 간격                      ② 난이도 정합성
  1, 3, 6, 10, 20, 42, 90단계        복습은 현재 구간 ±3에서만
  간격이 벌어지며 반복 = 기억에 남는다   사다리 위아래가 어긋나지 않는다
                    ↑
              둘을 동시에 만족할 수 없다
        (①을 지키면 1구간 미션이 90단계에 나온다)
```

**②를 골랐다.** 근거는 하나다.

> 1구간 미션 중 `커튼 열기`·`물 한 컵 마시기`·`기지개 한 번`은 **일일 미션에 이미 있다.**
> 일일 미션은 **매일 반복된다.** 단계 미션이 90단계에서 한 번 더 보여줄 필요가 없다.

즉 **①의 이득은 이미 다른 곳에서 나오고 있었다.** 잃는 것이 없다.

### 먼저 시도했고 실패한 방법도 적어 둔다

"늦게 도입된 미션은 최소 3회 나오게 하자"는 하한선(`MIN_REVIEWS = 3`)을 먼저 넣었다.

**안 됐다.** 굶는 미션 풀이 비지 않아서 규칙이 끝까지 그 풀만 봤고, 사람 관련 미션 위반이 **0개에서 7개로 늘었다.** 되돌렸다.

되는 방법은 기준을 두 개로 바꾸는 것이었다 — `(등장 횟수, 마지막 등장)`. 횟수를 먼저 보면 굶은 미션이 먼저 뽑힌다.

### 고친 결과

3종족 전부 같은 값이 나왔다.

| 단정 | 목표 | 전 | 후 |
|---|---|---|---|
| 복습 슬롯 중 1구간 출신 | 20% 이하 | 31% | **14%** ✓ |
| 7~9구간 미션이 최소 2회 등장 | 위반 0 | 13개 위반 | **0개** ✓ |
| 10구간 복습에 6구간 이전 출신 없음 | 0개 | 9개 전부 위반 | **0개** ✓ |
| 모든 단계가 3슬롯 | {3} | {3} | **{3}** ✓ |

도입 구간별 평균 등장 횟수가 이렇게 평평해졌다.

```
전  5.5  3.7  2.8  2.7  2.1  1.7  1.7  1.7  1.6  1.4
후  3.0  3.0  3.0  2.6  2.5  2.5  2.3  2.0  2.0  1.7
     ↑ 방 안                              사람 관련 ↑
   반복이 필요 없는 쪽이 줄고, 필요한 쪽이 늘었다
```

**그리고 이 셋을 `npm run check:curriculum`이 매번 검사한다.** 다시 무너지면 검사가 막는다. 검사가 실제로 작동하는지도 확인했다 — 옛 규칙을 일부러 넣어 보니 세 항목이 다 걸렸다.

> **여기서 배울 것:** "사다리 구조로 설계했다"와 "사다리가 됐다"는 다르다.
> 300슬롯을 실제로 생성해서 세어 보기 전까지 우리는 사다리라고 믿고 있었다.

## 6. 정직하게 — 아직 약한 곳

심사에서 물어보기 전에 우리가 먼저 말할 것들이다.

### 약점 1. 대부분이 자기 체크다

```
단계 미션 900슬롯 중 (100단계 × 3미션 × 3종족)
  사진 인증이 필요한 것   144  (16%)
  자기 체크로 끝나는 것   756  (84%)
```

(`npm run check:curriculum`의 `사진미션슬롯` 46+47+51. 공유 DB의 `Mission` STAGE 행은 **909**로 9개가 더 많다 — 100단계로 늘리기 전 3단계 시절의 고아 행이고 코드가 조회에서 배제한다. 지우지 않는 이유는 `scripts/prune-orphan-stage-missions.ts` 주석에 있다)

`20분 걷기`를 안 하고 눌러도 앱은 모른다. **행동과 보상 사이에 틈이 있다.**

우리가 하는 답 두 개.

1. **감시가 목적이 아니다.** 사진 미션조차 내용을 판정하지 않는다. 검증을 강화하면 은둔 상태의 사람이 앱을 떠난다 — 그게 더 큰 손실이다
2. **하지만 자동으로 확인 가능한 것도 자기 체크로 두고 있다.** 예를 들어 `글 쓰기`·`챗봇 대화`는 앱 안에서 일어나므로 시스템이 알 수 있다. 지금은 그것도 체크박스다. **여기는 개선 여지가 명확하다**

### 약점 2. 펫이 37단계에서 다 자란다

```
1단  2단        3단        4단(최종)
├───┼──────────┼──────────┼──────────────────────────────────────────┤
1                                    37                            100
                                     ↑ 여기서 시각적 보상이 끝난다
```

**"동네 한 바퀴"에서 펫이 다 자라고, 가장 어려운 63단계 동안 변화가 없다.** 사다리 위쪽에서 보상 체감이 가장 낮다.

대응 계획이 있다 — 펫 외출 시스템. 친밀도(사람과 닿아서 버는 재화)를 써서 펫을 밖에 내보내고, 돌아올 때 에피소드와 재화를 받는다. `docs/dev/pet.md`에 계획이 있고 **아직 미구현이다.**

### 약점 3. 오프라인 모임이 사다리와 안 붙어 있다

8구간이 "대화와 모임"인데, 실제 모임 기능은 커리큘럼과 **연결되어 있지 않다.** 71단계에 도달한 사람에게 모임을 권하지 않고, 모임에 나간 것이 단계 진행으로 이어지지도 않는다.

붙일 자리는 명확하다. 아직 안 붙였다.

## 7. 심사 예상 질문 — 한 줄 답

| 질문 | 답 |
|---|---|
| 이거 그냥 체크리스트 아닌가요 | 순서가 있는 체크리스트다. `현관문 열어두기`와 `면접 다녀오기`가 73칸 떨어져 있고, **그 간격이 이 서비스다** |
| 효과를 어떻게 아나요 | 임상 검증은 안 했다. 대신 **구조가 의도대로 되어 있는지는 측정한다** — 300슬롯을 생성해 세고, 3개 항목을 매번 자동 검사한다 |
| 왜 랭킹이 없나요 | 비교가 고립을 강화한다. 의도적 배제다(`SPEC.md` 5절) |
| 연속 달성을 끊으면요 | 처벌하지 않는다. "37일이 끊겼습니다"가 복귀를 막는다 |
| 거짓 체크를 막나요 | 84%는 못 막는다. **막는 쪽을 택하면 대상자가 떠난다**고 판단했다 — 감시가 아니라 발판이 목표다 |
| 유형 진단은 낙인이 아닌가요 | 내부 유형명 8종을 **화면과 API에 절대 노출하지 않는다.** 사용자는 자기 유형 이름을 보지 않는다 |
| AI는 어디에 쓰나요 | 챗봇 답변과 사진 판독. **미션 순서는 AI가 정하지 않는다** — 사람이 짠 고정 커리큘럼이다. 재현 가능해야 하기 때문 |
| 100단계를 다 하면요 | "정기적으로 나가고, 사람과 약속을 잡고, 배우거나 일을 알아보는" 상태. 그것이 종착점으로 명시돼 있다 |
