## 이 폴더의 규칙

- **숫자는 실측만 쓴다.** 어디서 쟀는지(파일·명령)를 함께 적는다
- **약점을 뺀 채로 쓰지 않는다.** 심사에서 물어보기 전에 우리가 먼저 적는다
- **원본 문서를 대체하지 않는다.** 각 문서 끝의 "다음에 읽을 것"이 원본을 가리킨다
- 값이 바뀌면 이 폴더도 바뀐다. **값을 고친 커밋에서 함께 고친다**
